# Architecture decisions

| #                                                                            | Decision                                                                 | In one line                                                                                                  |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| [0001](0001-publish-one-environment-module-per-kosmos-deployment.md)         | Publish one environment module per Kosmos deployment                     | Kosmos publishes one cohesive GCP environment module that deployment roots consume from Spacelift.           |
| [0002](0002-restrict-production-login-by-verified-google-email-domain.md)    | Restrict production login by verified Google email domain                | Allow only verified Google identities from three approved business domains.                                  |
| [0003](0003-authorize-google-workspace-separately-from-sign-in.md)           | Authorize Google Workspace separately from sign-in                       | Keep login scopes minimal and grant encrypted Gmail and Sheets access separately.                            |
| [0004](0004-run-integration-synchronization-through-cloud-tasks-and-a-pr.md) | Run integration synchronization through Cloud Tasks and a private worker | Cloud Scheduler and user actions enqueue retryable work for a scale-to-zero private Cloud Run worker.        |
| [0005](0005-make-accounts-own-customer-lifecycle-and-business-identity.md)   | Make accounts own customer lifecycle and business identity               | Accounts own lifecycle and opportunities while contacts remain people attached to accounts.                  |
| [0006](0006-import-cloudflare-domain-metadata-without-granting-mutation.md)  | Import Cloudflare domain metadata without granting mutation              | Kosmos reads Cloudflare domain metadata and creates renewal reminders without changing Cloudflare resources. |
| [0007](0007-consume-tiller-purchases-through-signed-product-aware-webhoo.md) | Consume Tiller purchases through signed product aware webhooks           | Kosmos consumes signed Tiller purchase events and maps immutable product IDs to accounts.                    |
| [0008](0008-verify-gmail-send-as-aliases-before-administrator-mapping.md)    | Verify Gmail send as aliases before administrator mapping                | Kosmos only maps Gmail aliases that Google reports as accepted for the connected user.                       |
| [0009](0009-use-private-photo-uploads-instead-of-importing-linkedin-prof.md) | Use private photo uploads instead of importing LinkedIn profile photos   | Kosmos stores user-uploaded contact photos and does not scrape or retain LinkedIn member profile images.     |
